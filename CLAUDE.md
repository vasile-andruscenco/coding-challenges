# Project rules

## Git: no autonomous commit or push

**It is forbidden to run `git commit` or `git push` on my own initiative.**

- Only commit or push when the user explicitly and specifically asks for that exact action.
- A vague request like "let's update the repo" is **not** authorization to commit or push.
- Making edits and staging files (`git add`) is allowed; stop there and let the user review.
- When in doubt, ask first.

## Git: no AI traces in commits

**Never add `Co-Authored-By` trailers, "Generated with Claude", or any AI/Claude
attribution to commit messages.** The user authors the solutions; commits must read as
fully human-authored. Keep commit messages clean — subject line and body only.
